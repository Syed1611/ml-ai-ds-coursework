# Machine Learning, AI & Data Science Coursework

A collection of Python notebooks and scripts developed during my MS in Computer Science at Oklahoma City University.

This repository documents my learning across data science, machine learning, and artificial intelligence—from small array-based implementations to exercises using datasets. The code was developed through instructor-guided sessions and individual coursework.

## Repository Structure

| Folder                     | Contents                                                                                                     |
| -------------------------- | ------------------------------------------------------------------------------------------------------------ |
| `Data Science/`            | Regression, classification, clustering, dimensionality reduction, and neural network exercises               |
| `Machine Learning/`        | Regression, neural networks, natural language processing, attention, transformers, and GPT-related exercises |
| `Artificial Intelligence/` | Exercises from my current AI coursework; updated as the course progresses                                    |
| `datasets/`                | Local datasets used by the notebooks                                                                         |

Within each subject, notebooks are grouped by topic. Filenames describe the method and input used—for example, a small array-based demonstration or an application to a named dataset.

Some topics appear in multiple subjects because they were revisited through different exercises.

## Datasets

Exercises use datasets including Abalone, Wine Quality, Banknote Authentication, Ionosphere, Iris, MNIST, and IMDb, along with text files used in NLP exercises.

Some notebooks load local files; others download data through libraries or external URLs. Refer to each notebook’s data-loading cells for the required files and source.

Datasets belong to their respective creators.

## Running the Notebooks

1. Clone or download this repository.
2. Open a notebook in Jupyter Notebook or upload it to Google Colab.
3. Install the libraries imported by that notebook.
4. Make the required dataset available and adjust file paths for your environment.
5. Run the cells in order from a fresh session.

Local data paths may need adjustment depending on your working directory. In Colab, upload the required files or make the repository available in the runtime.

Some neural network exercises may take longer to run or benefit from GPU acceleration. Saved outputs reflect previous executions; results can vary with library versions, random initialization, and training settings.

## Learning Context

These are educational implementations created to understand how the methods work and how they apply to different inputs and datasets.

The collection includes both implementations written with NumPy and exercises using machine learning frameworks. It is an evolving coursework repository rather than a production software package.
